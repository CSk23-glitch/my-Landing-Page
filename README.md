## 🚀 Getting Started (Deployment)

This project is a simple, single-page application built with HTML, CSS, and vanilla JavaScript for interactivity. It is hosted directly using **GitHub Pages**.

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/CSk23-glitch/my-Landing-Page.git](https://github.com/CSk23-glitch/my-Landing-Page.git)
    ```
2.  **Deployment:** The site is automatically deployed to the `gh-pages` branch upon pushing changes to the `main` branch.
3.  **Custom Domain Setup:** The repository is configured to handle a custom domain for a cleaner URL (refer to the CNAME file in the repository root).
